## Design brief: MINIMALISTIC, as minimal as possible, but really nice
- Single-page Next.js (App Router) + Tailwind, TypeScript, port 3000.
- Monochrome palette (off-white / near-black, light + dark via prefers-color-scheme) with ONE accent color. One typeface (e.g. Geist/Inter via next/font). Large type, generous whitespace, thin hairline borders, subtle hover/focus states.
- NO gradients, stock imagery, emoji clutter, carousels, or heavy animation. At most one tasteful fade-in.
- Sections in order: header (wordmark + few anchor links) -> hero (name, tagline, date/location, live countdown, "Register" CTA) -> tracks -> prizes -> schedule -> FAQ (accordion, native details/summary ok) -> register form -> team board (list, lookingFor filter, "post a team" form) -> tiny footer.
- Responsive, accessible (labels, focus rings, contrast, aria for errors/live regions), loading / error / empty states for every fetch.
- Typed API client matching the contract. Register form: show per-field errors from `error.details`; 409 ALREADY_REGISTERED shows a friendly message; 429 shows a try-again message; success state replaces the form. Team post form likewise; list refreshes after posting.
